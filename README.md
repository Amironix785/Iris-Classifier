# 🌸 Iris Flower Classifier

A simple Machine Learning project that predicts the species of an Iris flower based on its sepal and petal measurements.

The project uses a trained machine learning model from **Machine Learning for Kids** and provides a simple graphical interface built with **Python and Tkinter**.

The user enters four measurements:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The model then predicts the flower species and shows the prediction confidence.

---

## 📌 Project Overview

The goal of this project is to demonstrate how a Machine Learning model can be connected to a Python desktop application.

The project uses the well-known **Iris dataset**, which contains measurements of three different Iris flower species:

- 🌸 Iris Setosa
- 🌺 Iris Versicolor
- 🌷 Iris Virginica

The trained model receives four numerical values and returns the most likely flower species.
